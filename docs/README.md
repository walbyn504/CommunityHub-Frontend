# Documentación del frontend

Esta carpeta contiene la documentación técnica del frontend de CommunityHub,
desarrollado con Nuxt 4, Vue 3 y TypeScript.

## Contenido

- [Instalación y ejecución](instalacion.md)

La documentación de la API REST, MongoDB y AWS Lambda pertenece a sus
respectivos repositorios. Este frontend consume la API del backend y no se
conecta directamente a la base de datos.
